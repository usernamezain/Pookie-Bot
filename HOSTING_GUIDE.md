## Option A: VPS Server Deployment (PM2 / Linux)

A Linux Virtual Private Server (VPS) from providers like DigitalOcean, Hetzner, AWS, Vultr, or Linode offers complete control and reliability for running WhatsApp bots 24/7.

### Step 1: VPS SSH Access
Connect to your VPS server via SSH from your computer terminal:
```bash
ssh root@YOUR_SERVER_IP
```
*(Replace `YOUR_SERVER_IP` with your actual VPS IP address).*

---

### Step 2: Installing Dependencies (Node.js & PM2)
Update system packages and install Node.js (v18 or v20 LTS), Git, and PM2:

```bash
# Update Ubuntu package index
sudo apt update && sudo apt upgrade -y

# Install Git, Curl, and Build Essentials
sudo apt install -y git curl build-essential

# Install Node.js v20 LTS via NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify Node.js version
node -v # Should display v20.x.x

# Install PM2 Process Manager globally
sudo npm install -g pm2
```

---

### Step 3: Uploading / Cloning Repo
Navigate to your preferred directory and clone your bot repository:

```bash
cd /opt
git clone https://github.com/YOUR_USERNAME/Pookie-Bot.git
cd Pookie-Bot

# Install npm dependencies
npm install --production
```

---

### Step 4: Environment Setup
Create the `.env` file on your VPS server:
```bash
nano .env
```
Paste your configuration:
```env
BOT_NAME=POOKIE BOT
OWNER_NAME=Mughal Dev
GURU_API_KEY=guru
GIFTED_API_KEY=gifted
THUMBNAIL_URL=https://picsum.photos/seed/pookiebot/400/400
SMVD_KEY=
```
Save and exit (`Ctrl + O`, `Enter`, `Ctrl + X`).

---

### Step 5: Initial Pairing Execution
Run the bot interactively in your terminal once to authenticate with WhatsApp via Pairing Code:

```bash
node index.js
```

1. Enter your WhatsApp number when prompted.
2. Enter the generated 8-digit pairing code on your mobile phone (**WhatsApp** > **Linked Devices** > **Link a Device** > **Link with phone number instead**).
3. Once you see `✅ POOKIE BOT Connected Successfully!`, press `Ctrl + C` to stop the interactive session.

---

### Step 6: Running 24/7 with PM2
Now launch Pookie Bot in the background using PM2 so it stays online 24/7 even if you close SSH:

```bash
pm2 start index.js --name "pookie-bot"
```

Useful PM2 commands:
- **Check Status**: `pm2 status`
- **View Live Logs**: `pm2 logs pookie-bot`
- **Restart Bot**: `pm2 restart pookie-bot`
- **Stop Bot**: `pm2 stop pookie-bot`

---

### Step 7: Server Boot Auto-Restart
Ensure PM2 automatically starts Pookie Bot if your VPS reboots:

```bash
pm2 startup
# Copy and execute the command line output generated by the command above
pm2 save
```

## Option B: Free / Low-Cost Railway Cloud Deployment

Railway ([railway.com](https://railway.com)) allows hosting Node.js applications with free initial credits ($5 credit / trial).

> [!IMPORTANT]
> Because cloud platforms like Railway feature ephemeral file systems, you **must mount a Persistent Volume** to `/app/session` so your WhatsApp session authentication survives redeployments!

---

### Step 1: GitHub Repository Setup
1. Push your Pookie Bot codebase to a **GitHub repository** (Public or Private).
2. Ensure `.gitignore` ignores `node_modules` and `session/` directory.

---

### Step 2: Railway Account & New Project
1. Log in to [Railway](https://railway.com) using your GitHub account.
2. Click **New Project** > **Deploy from GitHub repo**.
3. Select your `Pookie-Bot` repository.

---

### Step 3: Environment Variables Configuration
In your Railway project dashboard:
1. Go to **Variables** tab.
2. Add the following key-value pairs:
   - `BOT_NAME`: `POOKIE BOT`
   - `OWNER_NAME`: `Mughal Dev`
   - `GURU_API_KEY`: `guru`
   - `GIFTED_API_KEY`: `gifted`
   - `THUMBNAIL_URL`: `https://picsum.photos/seed/pookiebot/400/400`
   - `SMVD_KEY`: `5dc721e18cmsh0d6b0f2e1b1f59cp1e000ajsnedde84a4491a`

---

### Step 4: Setting Up Persistent Volume for Session
1. In your Railway service view, click **Volumes**.
2. Click **Add Volume**.
3. Set the Mount Path to `/app/session`.
4. Save changes.

---

### Step 5: Pairing Authentication & Deployment
To complete WhatsApp pairing on Railway:

**Method 1: Local Session Transfer (Recommended)**
1. Pair Pookie Bot locally on your computer first (following [Local Setup Guide](file:///C:/Users/SHABBIR%20TRADERS/Desktop/Bot/Panel%20Web/Whatsapp-bots/Pookie-Bot-master/Pookie-Bot-master/RUN_LOCALLY.md)).
2. Zip the `session/` folder created locally.
3. Upload session contents to your Railway Persistent Volume (or upload session files to GitHub temporarily under a private repo).

**Method 2: Interactive Terminal pairing via Railway CLI**
1. Install Railway CLI: `npm install -g @railway/cli`
2. Login to Railway: `railway login`
3. Connect to interactive shell: `railway run node index.js`
4. Enter your phone number and pair using the code.

---

### Step 6: Maintaining Railway 24/7 Uptime
- Set **Restart Policy** to `On Failure` or `Always`.
- Monitor execution logs via Railway **Deployments** > **View Logs**.
- Monitor resource consumption to stay within the monthly credit limit.
